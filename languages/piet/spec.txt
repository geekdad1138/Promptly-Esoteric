Piet Language Specification
===========================
(Based on https://www.dangermouse.net/esoteric/piet.html)

## Overview
Piet is a programming language in which programs look like abstract paintings.
The language is named after Piet Mondrian.

## Colours
Piet uses 20 distinct colours:
- 18 colors arranged in a grid of 6 Hues × 3 Lightness levels
- White (#FFFFFF)
- Black (#000000)

### Hue Cycle (6 steps):
  red -> yellow -> green -> cyan -> blue -> magenta -> red

### Lightness Cycle (3 steps):
  light -> normal -> dark -> light

### Color Table (Hex Values):

| Hue      | Light    | Normal   | Dark     |
|----------|----------|----------|----------|
| Red      | #FFC0C0  | #FF0000  | #C00000  |
| Yellow   | #FFFFC0  | #FFFF00  | #C0C000  |
| Green    | #C0FFC0  | #00FF00  | #00C000  |
| Cyan     | #C0FFFF  | #00FFFF  | #00C0C0  |
| Blue     | #C0C0FF  | #0000FF  | #0000C0  |
| Magenta  | #FFC0FF  | #FF00FF  | #C000C0  |

## Codels
Individual pixels of colour are significant.  In enlarged programs,
the term "codel" means a block of colour equivalent to a single pixel
of code.

## Colour Blocks
A colour block is a contiguous block of any number of codels of one
colour.  Blocks adjacent only diagonally are NOT contiguous.

## Stack
Piet uses a stack for all data storage.  Values exist only as integers,
but may be read in or printed as Unicode character values.

## Program Execution
- Execution begins in the colour block containing the upper-left codel.
- Direction Pointer (DP): initially pointing RIGHT.
  May point: right, down, left, up.
- Codel Chooser (CC): initially pointing LEFT.
  May point: left, right.

### Traversal Rules:
1. Find the edge of the current colour block furthest in the DP direction.
2. Find the codel on that edge furthest in the CC's direction of the DP.
3. Move into the colour block containing the codel immediately in the
   direction of the DP from that codel.

### Numbers
Each non-black, non-white colour block represents an integer equal to
the number of codels in that block.  Values are NOT automatically pushed
onto the stack.

### Black Blocks and Edges
Black blocks and program edges restrict flow.  If the interpreter tries
to move into a black block or off an edge:
1. Toggle the CC.
2. If still blocked, rotate the DP clockwise one step.
3. Repeat alternating CC toggle and DP rotation.
4. After 8 failed attempts, the program terminates.

### White Blocks
White blocks are "free" zones.  The interpreter slides through white
codels in the direction of the DP until reaching a non-white colour
block.  Sliding through white does NOT execute any command.

## Command Table
Commands are determined by the transition from one colour block to the
next.  The number of steps along the Hue Cycle (ΔHue) and Lightness
Cycle (ΔLightness) determine the command:

| ΔLight\ΔHue | 0      | 1    | 2   | 3        | 4        | 5        |
|-------------|--------|------|-----|----------|----------|----------|
| 0           | (nop)  | push | pop | add      | subtract | multiply |
| 1           | divide | mod  | not | greater  | pointer  | switch   |
| 2           | dup    | roll | in(num)| in(char) | out(num) | out(char)|

### Command Details:
- push:     Pushes the value of the colour block just EXITED onto the stack.
- pop:      Pops the top value and discards it.
- add:      Pops top two, pushes their sum.
- subtract: Pops top two, pushes (second - top).
- multiply: Pops top two, pushes their product.
- divide:   Pops top two, pushes (second ÷ top) integer division.
- mod:      Pops top two, pushes (second mod top). Result has sign of divisor.
- not:      Replaces top with 0 if non-zero, 1 if zero.
- greater:  Pops top two, pushes 1 if second > top, else 0.
- pointer:  Pops top, rotates DP clockwise that many steps.
- switch:   Pops top, toggles CC that many times.
- dup:      Pushes a copy of the top value.
- roll:     Pops top two values (count, depth), rolls stack.
- in(num):  Reads integer from STDIN, pushes it.
- in(char): Reads char from STDIN, pushes its Unicode value.
- out(num): Pops top, prints as integer.
- out(char):Pops top, prints as Unicode character.

Operations that cannot be performed (e.g., popping from empty stack)
are simply ignored.
