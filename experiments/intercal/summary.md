# INTERCAL Experiment Summary

## Overview

An experiment for testing whether an agent can reason in INTERCAL,
C-INTERCAL's intentionally awkward dialect. INTERCAL uses unusual
statement prefixes, arrays, constants, operators, and I/O semantics.
