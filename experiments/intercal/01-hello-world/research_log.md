# INTERCAL Hello World Research Log

## Goal

Set up an INTERCAL/C-INTERCAL Hello World experiment using an array
assignment and READ OUT, matching the repository's Babel Loop pattern.

## Environment

C-INTERCAL is not installed in the current Windows environment. The
verification script therefore supports real execution when `ick` is
present and otherwise performs structural validation.

## Source

The initial program uses a 13-element 16-bit array, assigns the values,
reads it out, and terminates with GIVE UP.
